# SolarTech

Site educativo sobre energia solar fotovoltaica, criado a partir de um projeto de feira de ciências.

## O que o projeto tem

- Página inicial com resumo do tema.
- Calculadora para estimar consumo médio, potência do sistema, quantidade de placas e economia.
- Guia com perguntas frequentes sobre energia solar.
- Galeria com vídeos educativos.
- Mapa de irradiação solar e linha do tempo da evolução do setor no Brasil.
- Página sobre o projeto e contato.

## Como abrir

Abra o arquivo `index.html` no navegador. O projeto é estático e não precisa de servidor para funcionar.

## Publicação

Este site pode ser publicado no GitHub Pages usando a branch principal do repositório.
